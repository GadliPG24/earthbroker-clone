📋 Design Notes

  • Style: Low-fidelity Balsamiq-style wireframe — sketchy font, grayscale, dashed borders, "✕" image placeholders
  • Layout: All pages share a consistent header (top bar + logo + nav) and footer
  • Responsive: Grids collapse to single column on mobile
  • Key flows: Home → Classifieds → Detail | Home → Browse Categories → Category → Detail | Directory → A–Z Index
  • CTAs: WhatsApp contact, call now, share, save, subscribe — all identified per page
  • Ad placements: Banner ad slots marked on all appropriate pages
